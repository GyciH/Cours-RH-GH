Le concept

Intersections : rayon, plan, triangle

Cliquer sur un objet dans une vue 3D, savoir si un point est dans une forme, couper une hachure au bord d'une cellule : tout cela revient à lancer une droite et à chercher où elle rencontre la géométrie. La réponse est presque toujours un paramètre t.

55 min de lecture et de QCM Prérequis · 10, 17 et 50 Exemples · Hatch, Voronoi (Cuttlefish)

L'idée en une phrase

Un rayon est une origine plus t fois une direction ; l'intersecter avec une forme, c'est résoudre une équation en t, puis garder la plus petite solution positive.

L'analogie

Un pointeur laser dans une pièce. Le point rouge se pose sur le premier objet rencontré ; tout ce qui est derrière, sur la même ligne, reste dans l'ombre du premier.

À la fin, tu sais

  1. écrire un rayon et lire son paramètre t ;
  2. intersecter un rayon et un plan, et repérer les cas sans réponse ;
  3. dire si un point est dans un triangle (coordonnées barycentriques) ;
  4. écarter vite les objets avec leur boîte englobante.
À retenir t mesure le chemin parcouru le long du rayon. t < 0 : l'intersection est derrière l'origine. Plusieurs intersections : on les trie par t, et l'ordre donne ce qui est devant, ce qui est derrière, ou ce qui est dedans (pair-impair, cours 10).

Schéma 1 · Rayon et plan

Une seule équation, deux cas à écarter

Un plan est l'ensemble des points P tels que n · (P − P0) = 0 : le vecteur qui va de P0 à P est perpendiculaire à la normale n (cours 50). En remplaçant P par O + t D, il ne reste qu'une inconnue, t.

Exemple autonome · RhinoCommonstatic bool RayonPlan(Point3d o, Vector3d d, Plane plan, out double t) { t = double.NaN; double den = plan.Normal * d; // produit scalaire if (Math.Abs(den) < 1e-12) return false; // parallèle t = plan.Normal * (plan.Origin - o) / den; return t >= 0; // devant l'origine seulement } // RhinoCommon le fait aussi : Intersection.LinePlane(line, plan, out double t)

Rayon, segment ou droite

Même équation, trois lectures de t : une droite accepte tout t, un rayon t ≥ 0, un segment de A à B (D = B − A) seulement 0 ≤ t ≤ 1. LinePlane rend le t de la droite infinie : c'est à toi de le borner.

Le dénominateur

n · D dit sous quel angle le rayon arrive. Proche de 0, le rayon frôle le plan : t devient énorme et très sensible aux arrondis. On compare à une tolérance, jamais à zéro exact (cours 49).

Piège courant Beaucoup de fonctions d'intersection rendent un booléen et passent le résultat par out. Si le booléen vaut false, la valeur sortie n'a pas de sens. L'ignorer, c'est utiliser un point au hasard le jour où les deux droites sont parallèles.

Schéma 2 · Rayon et triangle

Dans le plan, puis dans le triangle

Un maillage n'est qu'une liste de triangles. Un point du plan d'un triangle s'écrit comme un mélange de ses trois sommets : les coordonnées barycentriques. Il est dans le triangle si les trois parts sont positives. L'algorithme de Möller et Trumbore trouve t, u et v d'un seul coup.

Exemple autonome · Möller–Trumbore en RhinoCommonVector3d e1 = b - a, e2 = c - a; Vector3d p = Vector3d.CrossProduct(d, e2); double det = e1 * p; if (Math.Abs(det) < 1e-12) return false; // rayon parallèle au triangle Vector3d s = o - a; double u = (s * p) / det; if (u < 0 || u > 1) return false; Vector3d q = Vector3d.CrossProduct(s, e1); double v = (d * q) / det; if (v < 0 || u + v > 1) return false; double t = (e2 * q) / det; return t > 1e-9; // devant, pas sur l'origine

Les parts servent ailleurs

u et v ne font pas que trancher dedans ou dehors : ils mélangent ce que portent les sommets. Couleur, normale ou coordonnée de texture au point touché valent (1 − u − v) × celle de A + u × celle de B + v × celle de C.

Dans RhinoCommon

Intersection.MeshRay(maillage, rayon) rend le t du premier triangle touché (négatif s'il n'y en a pas), et RayShoot fait rebondir un rayon sur des surfaces. Côté web, le Raycaster de three.js fait le même travail au clic.

Piège courant Un rayon qui passe exactement sur l'arête commune à deux triangles peut être compté deux fois, ou zéro, selon les arrondis. Pour un simple clic, peu importe ; pour compter les traversées (pair-impair), le résultat bascule. On change alors un peu la direction du rayon et on recommence.

Schéma 3 · La boîte englobante d'abord

Écarter vite, calculer ensuite

Tester un rayon contre cent mille triangles coûte cher. On teste d'abord la boîte englobante alignée sur les axes : si le rayon la rate, il rate tout ce qu'elle contient. Le test des tranches ne demande que six divisions.

Exemple autonome · test des tranches, en 2Ddouble tx1 = (min.X - o.X) / d.X, tx2 = (max.X - o.X) / d.X; // entrée et sortie en X double ty1 = (min.Y - o.Y) / d.Y, ty2 = (max.Y - o.Y) / d.Y; // entrée et sortie en Y double tEntree = Math.Max(Math.Min(tx1, tx2), Math.Min(ty1, ty2)); double tSortie = Math.Min(Math.Max(tx1, tx2), Math.Max(ty1, ty2)); bool touche = tEntree <= tSortie && tSortie >= 0; // en 3D : même chose avec Z

Dans les deux tranches à la fois

Le rayon est dans la tranche des X entre deux valeurs de t, dans celle des Y entre deux autres. Il est dans la boîte là où les deux intervalles se recouvrent : du plus grand des débuts au plus petit des fins.

Des boîtes dans des boîtes

En rangeant les triangles dans des boîtes de plus en plus petites (un arbre, comme le R-tree du cours 17), un rayon n'ouvre que les boîtes qu'il traverse. Rhino et three.js s'appuient sur ce genre d'arbre pour garder le clic instantané.

Piège courant Un rayon parallèle à un axe a une composante nulle : d.X = 0. La division donne alors ±∞ (cours 49), et le test marche encore… sauf si l'origine est pile sur le bord de la boîte, où 0 / 0 donne NaN et fausse les Max et Min. On traite ce cas à part.

Glossaire

Rayon
Une demi-droite : une origine et une direction, parcourue pour t ≥ 0.
Lancer de rayon
Chercher ce que touche un rayon : clic, ombres, test d'intérieur.
Barycentrique
Les trois parts (somme 1) qui écrivent un point comme mélange des sommets.
Test des tranches
Le test rayon-boîte par recouvrement des intervalles de t sur chaque axe.
Pair-impair
Compter les traversées : un nombre impair veut dire que l'on est dedans.
