Le concept

Eto.Forms : une fenêtre pour Rhino

Une commande demande parfois plus qu'une invite : plusieurs réglages à la fois, une liste, une case à cocher. Rhino construit ses propres fenêtres avec Eto.Forms, une bibliothèque qui écrit l'interface une fois et la montre avec les contrôles natifs de Windows comme de macOS.

50 min de lecture et de pratique Niveau · intermédiaire Prérequis · 164, 165 Exemples · Eto.Forms, Rhino.UI, Dialog

L'idée en une phrase

Eto.Forms décrit une fenêtre par un arbre de layouts et de contrôles, sans coordonnées ; chaque système la dessine avec ses propres contrôles. Dans Rhino, on la montre modale, semi-modale ou en panneau, et on la relie à un objet de réglages.

La situation

Ta commande Cercle demande un rayon, un plan et s'il faut remplir le cercle. Trois invites successives agacent. Une petite boîte, avec OK et Annuler, rassemble les trois réglages, et sur macOS elle a l'air d'une boîte macOS.

À la fin, tu sais

  1. expliquer pourquoi Rhino passe par une bibliothèque multiplateforme ;
  2. composer une fenêtre avec des layouts, sans coordonnées ;
  3. choisir entre modale, semi-modale et panneau ;
  4. relier les contrôles à un objet de réglages.
À retenir Une fenêtre Eto est un arbre : layouts qui rangent, contrôles qui saisissent. On lui donne Rhino comme propriétaire, un bouton par défaut et un d'abandon, et on n'applique rien si l'utilisateur annule.

Schéma 1 · La mise en page

Des layouts, pas des coordonnées

Eto propose une seule API de contrôles (Dialog, Button, NumericStepper…). On ne les place pas au pixel près : on les range dans des layouts. StackLayout empile, TableLayout aligne en lignes et colonnes. La fenêtre prend la taille de son contenu.

Exemple autonome · C#, une grille de réglagesvar rayon = new NumericStepper { Value = 10, DecimalPlaces = 1, MinValue = 0 }; var ok = new Button { Text = "OK" }; var non = new Button { Text = "Annuler" }; var boite = new Dialog<bool> { Title = "Cercle", Padding = 10, DefaultButton = ok, AbortButton = non }; boite.Content = new StackLayout { Spacing = 8, Items = { new TableLayout(new TableRow("Rayon", rayon)), new StackLayout { Orientation = Orientation.Horizontal, Spacing = 6, Items = { ok, non } } } }; ok.Click += (s, e) => boite.Close(true); non.Click += (s, e) => boite.Close(false);

Padding et Spacing

Padding met de l'air autour du contenu ; Spacing, entre les éléments d'un layout. Deux réglages suffisent à une fenêtre régulière.

Entrée et Échap

DefaultButton répond à Entrée, AbortButton à Échap : l'utilisateur retrouve les gestes de toutes les boîtes du système.

Piège courant Fixer la taille de la fenêtre et des contrôles. Une police plus grande, une traduction plus longue ou un écran haute densité, et les textes sont coupés.

Schéma 2 · Montrer la fenêtre

Modale, semi-modale ou panneau

Une boîte modale bloque Rhino jusqu'à la réponse ; une semi-modale laisse encore manipuler la vue ; une fenêtre non modale ou un panneau reste ouvert pendant le travail. Dans tous les cas, on donne Rhino comme propriétaire.

Exemple autonome · C#, la plus petite boîteusing Eto.Forms; using Rhino.UI; var boite = new Dialog { Title = "Bonjour", Padding = 10, Content = new Label { Text = "Une fenêtre Eto dans Rhino" } }; boite.ShowModal(RhinoEtoApp.MainWindow);

Le propriétaire

RhinoEtoApp.MainWindow donne la fenêtre principale de Rhino comme parent : la boîte reste devant et se centre sur elle.

Semi-modale

ShowSemiModal(doc, RhinoEtoApp.MainWindow) laisse pivoter et zoomer pendant que la boîte attend : utile pour choisir en regardant.

Piège courant Ouvrir la boîte sans propriétaire. Elle peut passer derrière Rhino ; l'utilisateur croit le logiciel figé alors qu'une fenêtre attend sa réponse.

Schéma 3 · Relier les valeurs

La liaison de données

Pour lire les valeurs, on peut interroger chaque contrôle après OK. Dès qu'il y a plusieurs réglages, on lie plutôt chaque contrôle à une propriété d'un objet de réglages, donné à la boîte comme DataContext.

Exemple autonome · C#, lier un contrôle à un objetclass Reglages { public double Rayon { get; set; } = 10; } var r = new Reglages(); rayon.ValueBinding.BindDataContext((Reglages x) => x.Rayon); boite.DataContext = r; if (boite.ShowModal(RhinoEtoApp.MainWindow)) // true : OK Ajouter(r.Rayon); // false : on ne touche à rien

Lire à la main

Pour deux ou trois champs, lire rayon.Value après OK suffit. La liaison prend l'avantage quand les réglages se multiplient ou se réutilisent.

Annuler, c'est rien

Si la boîte rend false, la commande sort sans rien modifier, comme une invite à laquelle on répond Échap.

Piège courant Appliquer les réglages au fil de la saisie, puis oublier de revenir en arrière si l'utilisateur annule. Le document garde un état que personne n'a validé.

Mise en pratique

Une boîte de réglages pour un cercle

Tu écris un script qui ouvre une boîte avec un rayon, OK et Annuler, puis ajoute un cercle seulement si l'utilisateur valide.

Exercice guidé

  1. Lance ScriptEditor, nouveau script C#. Ajoute using Eto.Forms; using Rhino.UI;.
  2. Recopie la grille de réglages du schéma 1 (rayon, OK, Annuler).
  3. Montre la boîte : bool ok = boite.ShowModal(RhinoEtoApp.MainWindow);.
  4. Si ok, ajoute var doc = RhinoDoc.ActiveDoc; puis doc.Objects.AddCircle(new Circle(rayon.Value));.
  5. Termine par doc.Views.Redraw(); dans le même bloc, puis exécute.
  6. Relance, tape un rayon, et appuie sur Échap au lieu de cliquer OK.
Résultat attendu Une boîte Cercle s'ouvre devant Rhino, avec le champ Rayon et deux boutons. OK ou Entrée ajoute un cercle centré sur l'origine, du rayon saisi. Annuler ou Échap ferme la boîte et le document ne change pas.
Défi Ajoute une case à cocher « Remplir » et, si elle est cochée, ajoute aussi une surface plane bordée par le cercle.

  • ☐ La boîte reste devant Rhino et se centre sur lui.
  • ☐ Entrée valide, Échap annule.
  • ☐ Le cercle a bien le rayon saisi.
  • ☐ Après Annuler, Ctrl+Z n'a rien à défaire.

Aide-mémoire et glossaire

En résumé

Eto.Forms écrit une fenêtre une fois et la montre avec les contrôles natifs de chaque système : c'est ce que Rhino utilise. On compose la fenêtre avec des layouts (StackLayout, TableLayout), on lui donne RhinoEtoApp.MainWindow comme propriétaire, un bouton par défaut et un d'abandon. Modale, semi-modale ou panneau selon le besoin ; la liaison de données garde contrôles et réglages d'accord, et Annuler ne modifie rien.

Le défi, une solution

Ajoute var remplir = new CheckBox { Text = "Remplir" }; dans une nouvelle ligne du TableLayout. Après OK, si remplir.Checked == true (le type est bool?), construis la surface avec Brep.CreatePlanarBreps à partir de la courbe du cercle (circle.ToNurbsCurve()) et ajoute chaque Brep obtenu au document.

Glossaire

Eto.Forms
Bibliothèque d'interface multiplateforme utilisée par Rhino.
Plateforme
La partie d'Eto qui traduit les contrôles en contrôles natifs d'un système.
Layout
Un conteneur qui range ses contrôles : pile, grille.
Modale
Une fenêtre qui bloque le logiciel jusqu'à sa fermeture.
Liaison de données
Un lien qui garde un contrôle et une propriété d'accord.
