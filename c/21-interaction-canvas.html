Le concept

Interaction
sur le canvas

Peindre ne suffit pas : un interrupteur doit basculer, un curseur glisser, un réglage s'annuler. Grasshopper fournit tout le circuit ; il suffit de savoir où répondre.

50 min de lecture et de QCM Prérequis · 11 cycle de vie · 20 attributs Exemples · FeuilleAttributs, MenuReglages, ConceptionTexte (SnapSet)

L'idée en une phrase

Le canvas offre chaque évènement de souris aux attributs de l'objet pointé, qui répondent par un GH_ObjectResponse : Ignore, Handled, Capture ou Release. Le menu, la saisie de texte et l'annulation viennent eux aussi du SDK.

L'analogie

Un standard téléphonique. Il passe l'appel au bureau visé. Le bureau dit « pas pour moi » et le standard s'en occupe, ou « c'est réglé », ou « je garde la ligne » jusqu'à ce qu'il raccroche.

À la fin, tu sais

  1. lire les quatre réponses et suivre un geste de l'enfoncement au relâchement ;
  2. dire quel objet reçoit un clic, grâce à IsPickRegion ;
  3. construire un menu contextuel et une saisie avec les outils natifs ;
  4. poser un seul enregistrement d'annulation par geste.
À retenir SnapSet n'écrit aucune fenêtre ni aucune pile d'annulation. La souris passe par RespondToMouse*, le menu par AppendAdditionalMenuItems, la saisie par ShowTextInputBox, l'annulation par RecordUndoEvent (décision 0 de CLAUDE.md).

Schéma 1 · Les quatre réponses

Un geste, de l'enfoncement au relâchement

Les attributs ont quatre méthodes à redéfinir : RespondToMouseDown, Move, Up et DoubleClick. Chacune rend une réponse qui dit au canvas ce qu'il doit faire ensuite.

Ce que dit chaque réponse

Ignore : pas pour moi, le canvas applique son geste par défaut. C'est ce que rend base. Handled : traité, le canvas s'arrête là. Capture : traité, et la suite du geste est pour moi. Release : traité, je rends la souris.

Le gabarit des feuilles

FeuilleAttributs écrit le geste une fois. Chaque feuille ne fournit que trois méthodes abstraites : Enfoncer (vrai si elle capte), Relacher et Abandonner. Au-delà du seuil de glisser de Windows, l'enfoncement est abandonné et la feuille se déplace.

FeuilleConception.cs · 347–364public override GH_ObjectResponse RespondToMouseUp(GH_Canvas canvas, GH_CanvasMouseEvent e) { if (_enfoncement == null) return base.RespondToMouseUp(canvas, e); try { Relacher(canvas, e); } finally { // LA CAPTURE EST RENDUE DANS UN finally (CONTRAT C6, comme Magpie) Abandonner(); _enfoncement = null; Instances.RedrawCanvas(); } return GH_ObjectResponse.Release; }
Piège courant Oublier le cas d'erreur. Si Relacher lève une exception et que rien ne remet l'état à zéro, le bouton reste peint enfoncé et le geste suivant part de travers. Le contrat C6 le dit : « sinon une exception fige le canvas ». D'où le finally.

Schéma 2 · Le pointage

Qui reçoit le clic ? IsPickRegion

Le canvas demande à chaque objet, du dernier au premier dans l'ordre du document, si le point est dans sa zone de pointage : IsPickRegion(point). Le premier qui dit oui reçoit l'évènement. Par défaut, la zone est Bounds.

ConteneurAttributs.cs · 151–161 et CibleDeDepot.cs · 247–257, condensépublic override bool IsPickRegion(PointF point) { var membres = registre.MembresPresents(Conteneur) .Select(m => m.Attributes is ConstituantAttributs ca ? ca.ZoneDePointage : m.Attributes.Bounds); return PointageConteneur.EstAuConteneur(Bounds, membres, point); } // EstAuConteneur : dans ma boîte, et dans aucune boîte de membre. if (!boite.Contains(point)) return false; foreach (var membre in boitesDesMembres) if (membre.Contains(point)) return false; return true;

Pourquoi ne pas compter sur l'ordre

Un conteneur et ses membres se recouvrent. Sans exclusion, le gagnant dépendrait de l'ordre du document, qui change à chaque copier-coller. En cédant la boîte de chaque membre direct, chaque niveau le fait pour le suivant : la règle devient récursive.

Une règle pure, testée hors Rhino

EstAuConteneur ne prend que des rectangles et un point. Elle vit dans une classe statique sans Grasshopper : un test unitaire la vérifie sans ouvrir Rhino (cours 26). L'attribut ne fait que lui fournir les boîtes.

Piège courant Une zone de pointage plus petite que ce qu'on voit. Le Séparateur est fin : sa zone est étendue à sa marge (ZoneDePointage), et le conteneur cède cette zone-là, pas la boîte peinte. Sinon on ne pourrait presque jamais l'attraper.

Schéma 3 · Menu et saisie natifs

L'inspecteur, c'est le menu contextuel

Pas de panneau de propriétés : les réglages d'un constituant s'ajoutent au clic droit, après le menu natif, par AppendAdditionalMenuItems. Voici le menu d'un Interrupteur.

MenuReglages.cs · 120–134, condenséprivate static void AjouterTexte(ToolStripDropDown menu, Constituant c, ProprieteNoeud prop) { var titre = GH_DocumentObject.Menu_AppendItem(menu, prop.Titre + " (Entrée pour valider)"); titre.Enabled = false; GH_DocumentObject.Menu_AppendTextItem(menu, courant, (sender, e) => { if (e.KeyCode != Keys.Enter) return; string saisi = sender.Text ?? string.Empty; sender.CloseEntireMenuStructure(); c.Regler(prop.Titre, table, saisi, c.LireTexte(table, ValeurDuNoeudNeuf(c, prop))); }, null, true); }

Pourquoi BeginInvoke

Le double-clic arrive pendant que le canvas traite la souris. canvas.BeginInvoke repousse l'ouverture de la saisie juste après, sur le même fil d'interface : le double-clic rend Handled tout de suite, puis la boîte s'ouvre.

Un réglage, un Ctrl+Z

Tout élément finit dans Regler : rien si la valeur est la même, sinon Modifier, qui pose l'enregistrement d'annulation avant d'écrire. Annuler est le Ctrl+Z de Grasshopper, avec le libellé du réglage.

Piège courant Oublier le test sur Entrée. Le gestionnaire de Menu_AppendTextItem est appelé à chaque touche. Sans if (e.KeyCode != Keys.Enter) return;, taper « visible » ferait sept réglages et sept enregistrements d'annulation.

Glossaire

Réponse d'objet
Le GH_ObjectResponse qui dit au canvas quoi faire après un évènement.
Capture
La souris gardée par un objet jusqu'à ce qu'il la rende.
Zone de pointage
Les points pour lesquels IsPickRegion répond oui.
Saisie native
La boîte de texte de Grasshopper, posée sur le canvas ou dans le menu.
Enregistrement
L'état d'un objet photographié pour Ctrl+Z, sous un libellé.
