Le concept

Python dans Rhino 8

Automatiser une tâche répétitive, analyser un modèle, tester une idée en dix lignes : Python est la porte d'entrée la plus courte vers la programmation de Rhino. Rhino 8 la rénove avec un éditeur unique et CPython 3, qui ouvre l'accès aux paquets de tout l'écosystème Python.

50 min de lecture et de pratique Niveau · débutant Prérequis · 164, 9 Exemples · Python 3, rhinoscriptsyntax, RhinoCommon

L'idée en une phrase

Rhino 8 exécute Python avec deux moteurs, CPython 3 et IronPython 2.7, depuis un même éditeur ; les deux appellent RhinoCommon. rhinoscriptsyntax offre des fonctions simples, RhinoCommon le contrôle complet, et un script peut déclarer ses paquets.

La situation

Tu dois placer des points régulièrement sur une centaine de courbes et noter leur longueur. À la main, une heure ; en C#, un projet à créer et compiler. Un script Python de quinze lignes, lancé depuis l'éditeur, le fait en une seconde.

À la fin, tu sais

  1. choisir le moteur Python d'un script ;
  2. passer de rhinoscriptsyntax à RhinoCommon ;
  3. déclarer un paquet externe ;
  4. écrire un composant Python dans Grasshopper.
À retenir #! python3 pour le Python moderne et ses paquets, #! python2 pour les anciens scripts. rhinoscriptsyntax pour aller vite, RhinoCommon pour tout contrôler. Un script de composant rend des sorties, il n'ajoute rien au document.

Schéma 1 · Les deux étages

rhinoscriptsyntax et RhinoCommon

rhinoscriptsyntax rassemble des fonctions simples qui travaillent sur des identifiants d'objets et mettent le document à jour. Elles appellent elles-mêmes RhinoCommon, l'API .NET complète, qu'on importe directement quand on a besoin de plus.

Exemple autonome · Python 3, les deux étages#! python3 import rhinoscriptsyntax as rs import Rhino.Geometry as rg id = rs.GetObject("Courbe", rs.filter.curve) pts = rs.DivideCurve(id, 10) # étage simple : des Point3d for p in pts: rs.AddPoint(p) crv = rs.coercecurve(id) # passage à RhinoCommon print(crv.GetLength(), crv.IsClosed)

Identifiants

rs manipule des GUID : chaque fonction retrouve l'objet dans le document. Simple, mais chaque appel passe par le document.

Objets

RhinoCommon travaille sur la géométrie en mémoire. On calcule tout, puis on n'ajoute au document que le résultat.

Piège courant Ajouter au document chaque résultat intermédiaire. Le document se remplit, l'annulation aussi ; on calcule en mémoire et on n'ajoute que ce qui doit rester.

Schéma 2 · Les paquets

Déclarer ce dont le script a besoin

En CPython 3, un commentaire en tête de script déclare un paquet : l'éditeur l'installe avec pip dans l'environnement Python de Rhino au premier lancement. Le script porte ainsi ses dépendances.

Exemple autonome · Python 3, un paquet déclaré#! python3 # r: numpy import numpy as np import rhinoscriptsyntax as rs ids = rs.GetObjects("Courbes", rs.filter.curve) L = np.array([rs.CurveLength(i) for i in ids]) print("moyenne", L.mean(), "écart-type", L.std())

Bibliothèque standard d'abord

math, statistics, json, csv sont déjà là. Un paquet externe se justifie quand il apporte vraiment quelque chose.

IronPython à part

IronPython tourne sur .NET : il ne charge pas les paquets compilés en C comme numpy. Pour eux, #! python3.

Piège courant Installer un paquet à la main dans un Python du système, puis s'étonner que Rhino ne le trouve pas. Rhino a son propre environnement ; la déclaration en tête de script vise le bon.

Schéma 3 · Dans Grasshopper

Le composant de script Python

Dans Grasshopper, le composant Python 3 Script expose ses entrées comme des variables et lit ses sorties dans des variables. On renomme les entrées, on choisit leur type, et le code ne connaît que ces noms.

Exemple autonome · Python 3, dans un composant# entrées : courbe (Curve), n (int) ; sortie : a import Rhino.Geometry as rg t = courbe.DivideByCount(n, True) a = [courbe.PointAt(x) for x in t]

Recalculé souvent

Le composant tourne à chaque changement en amont. Il doit rendre des sorties, pas ajouter des objets au document Rhino.

Et l'existant ?

Les composants IronPython (GhPython) restent disponibles : un script qui marche peut y rester, on migre quand un paquet ou Python 3 apporte quelque chose.

Piège courant Appeler rs.AddPoint dans un composant Grasshopper. À chaque recalcul, de nouveaux points s'ajoutent au document Rhino ; on rend les points en sortie et on cuit (Bake) si besoin.

Mise en pratique

Des points sur une courbe, et sa longueur

Tu écris un script qui demande une courbe, y place des points régulièrement espacés, et affiche sa longueur et le nombre de points.

Exercice guidé

  1. Dessine une courbe dans Rhino, puis lance ScriptEditor.
  2. Nouveau script Python 3 ; vérifie que la première ligne est #! python3.
  3. Recopie l'exemple du schéma 1, et exécute avec le bouton de lecture ou F5.
  4. Sélectionne ta courbe : vérifie les 11 points (10 segments, extrémités comprises sur une courbe ouverte).
  5. Remplace 10 par rs.GetInteger("Segments", 10, 1) et relance.
  6. Ajoute à la fin rs.MessageBox("%.2f" % crv.GetLength()).
Résultat attendu Des points apparaissent le long de la courbe, régulièrement espacés, extrémités comprises. La sortie de l'éditeur affiche la longueur et si la courbe est fermée ; une boîte de message rappelle la longueur. Les points sont des objets ordinaires du document.
Défi Fais en sorte qu'Échap à la sélection de la courbe ne provoque pas d'erreur, puis calcule les mêmes points sans rs.DivideCurve, avec RhinoCommon.

Aide-mémoire et glossaire

En résumé

Rhino 8 exécute Python depuis un seul éditeur, avec deux moteurs : CPython 3 (#! python3), qui accède aux paquets pip déclarés en tête par # r:, et IronPython 2.7 (#! python2) pour les anciens scripts. rhinoscriptsyntax offre des fonctions simples sur des identifiants, RhinoCommon le contrôle complet en mémoire. Dans Grasshopper, le composant Python 3 Script expose ses entrées en variables et rend des sorties, sans toucher au document.

Le défi, une solution

rs.GetObject rend None quand on annule : ajoute if id is None: raise SystemExit (ou mets le code dans une fonction et fais return). Côté RhinoCommon : t = crv.DivideByCount(n, True) rend des paramètres, puis pts = [crv.PointAt(x) for x in t] ; DivideByCount peut rendre None si la division échoue, à tester aussi.
