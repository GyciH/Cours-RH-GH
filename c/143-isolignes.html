Le concept

Les isolignes

Les courbes de niveau d'une carte, les isobares d'une météo, les contours de Cuttlefish : partout la même question, où le champ vaut-il exactement telle valeur ? On ne connaît le champ qu'aux nœuds d'une grille. Marching squares devine le reste case par case, avec une erreur qu'on sait chiffrer et une ambiguïté qu'on sait trancher.

45 min de lecture et de QCM Prérequis · 49, 138, 140 Exemples · Cuttlefish

L'idée en une phrase

Dans chaque case, les coins sous le niveau et ceux au-dessus disent quelles arêtes l'isoligne traverse ; une interpolation dit où.

L'analogie

Une marée qui monte sur un damier de rochers : pour chaque carré, tu regardes quels coins sont mouillés, et tu traces la ligne d'eau entre eux.

À la fin, tu sais

  1. écrire marching squares ;
  2. chiffrer l'erreur selon le pas ;
  3. reconnaître et trancher une selle ;
  4. recoudre les segments.
À retenir Chaque case se traite seule, sans connaître ses voisines : c'est ce qui rend l'algorithme simple et parallélisable, et ce qui oblige à recoudre ensuite.

Schéma 1 · La finesse de la grille

Moitié moins de pas, quatre fois moins d'erreur

Autour d'un seul point, la distance a pour isolignes des cercles parfaits. On a donc pu mesurer l'écart entre ce que trace l'algorithme et la vraie courbe, sur une recopie hors de Rhino.

Exemple autonome · C#, le point de passage sur une arêteif ((va < niveau) != (vb < niveau)) { double t = (niveau - va) / (vb - va); // vb ≠ va, sinon pas de traversée croisements.Add(pa + t * (pb - pa)); }

Pourquoi le carré

Sur une arête, on remplace une courbe par sa corde. L'écart entre une courbe et sa corde croît comme le carré de la longueur : c'est le même calcul qu'au cours 52 pour les polylignes.

Le prix

Diviser le pas par deux quadruple le nombre de cases, donc d'évaluations du champ. Pour gagner un chiffre de précision, il faut environ trois fois plus de points par côté.

Piège courant Comparer une isoligne à une valeur exacte avec la tolérance du document. À un pas de 1, le cercle tracé s'écartait de 0,05 du vrai (mesuré sur recopie) : la grille fixe la précision, pas Rhino.

Schéma 2 · L'ambiguïté

La case en selle

Quand les coins alternent, dessus et dessous en diagonale, l'isoligne traverse les quatre arêtes. Deux tracés sont possibles, et les seuls coins ne permettent pas de choisir.

Exemple autonome · C#, trancher par la valeur au centreif (croisements.Count == 4) { bool centreDessous = (v0 + v1 + v2 + v3) / 4 < niveau; // ou le vrai champ au centre if (centreDessous == (v0 < niveau)) Relier(0, 1, 2, 3); else Relier(0, 3, 1, 2); }

Ce que change le mauvais choix

Les lignes ne se croisent pas ; elles se rejoignent mal. Deux îlots voisins fusionnent, ou une vallée se coupe en deux. Le dessin reste propre, la topologie est fausse.

Quand les selles apparaissent

Entre deux attracteurs, le champ de distance forme un col. Avec beaucoup d'attracteurs et une grille assez fine pour voir les cols, les cases ambiguës arrivent.

Piège courant Tester l'algorithme sur un ou deux attracteurs et conclure qu'il n'y a pas d'ambiguïté. Deux attracteurs : aucune selle ; trente : 10 selles, dont 3 mal reliées (mesuré sur recopie).

Schéma 3 · Recoudre

Des segments qui se touchent presque

Chaque arête intérieure est vue par deux cases, qui calculent chacune son point de passage. Le même point, deux calculs : on a compté combien différaient.

Exemple autonome · C#, calculer chaque arête une seule foisvar passage = new Dictionary<(int, int, int, int), Point3d>(); // clé : l'arête, coins ordonnés Point3d Passage(int a0, int a1, int b0, int b1) => ...; // calcul fait une fois, dans un seul sens

Deux façons de recoudre

Joindre ensuite avec une tolérance, comme le fait Cuttlefish avec Curve.JoinCurves. Ou mémoriser chaque point par arête : les segments partagent alors exactement leurs extrémités.

Le lien avec union-find

Avec des points mémorisés par arête, recoudre revient à regrouper les segments qui partagent une extrémité : c'est exactement le travail d'union-find (cours 138).

Piège courant Recoudre en comparant les extrémités par ==. Un point partagé sur trente environ différait au bit près (mesuré sur recopie) : les courbes se seraient coupées en morceaux.

Glossaire

Isoligne
La courbe où un champ prend une valeur donnée.
Marching squares
Tracer une isoligne case par case sur une grille de valeurs.
Interpolation linéaire
Estimer une valeur entre deux autres comme sur une droite.
Selle
Un col : le champ monte dans une direction et descend dans l'autre.
Champ de distance
En chaque point, la distance au plus proche attracteur.
