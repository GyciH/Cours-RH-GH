Le concept

Les arbres de données en pratique

Le cours 08 a posé le vocabulaire : chemins, branches, accès item, list ou tree. Ici, on met les mains dans l'arbre : le lire, prévoir ce qu'un composant fera de deux arbres, et lui donner la forme dont la suite de la définition a besoin.

50 min de lecture et de pratique Niveau · intermédiaire Prérequis · 8, 11 Exemples · Grasshopper, Param Viewer, Flip Matrix

L'idée en une phrase

Un arbre range les mêmes données selon une intention : par courbe, par colonne, par rangée. Bien travailler avec, c'est choisir cette intention et faire suivre la forme, avant chaque composant qui compte.

La situation

Une grille de points doit devenir des lignes. Polyline dessine les colonnes mais pas les rangées, et sur une liste aplatie il trace un zigzag. Flip Matrix range les mêmes points par rangées : la même Polyline dessine alors les lignes horizontales.

À la fin, tu sais

  1. lire un chemin et dire d'où vient une branche ;
  2. prévoir comment deux arbres s'associent ;
  3. restructurer un arbre (Flip Matrix, Simplify, Path Mapper…) ;
  4. garder la structure d'entrée dans un composant écrit en C#.
À retenir Un indice s'ajoute au chemin chaque fois qu'un composant rend une liste par élément. Deux arbres s'associent branche à branche, dans l'ordre, la dernière branche répétée. On donne à l'arbre la forme voulue juste avant le composant qui l'exploite.

Schéma 1 · Lire un arbre

Le chemin raconte l'histoire

Le chemin {0;2;3} se lit de gauche à droite : l'entrée d'origine, puis la troisième courbe, puis son quatrième point. Chaque composant qui rend plusieurs résultats par élément ajoute un indice à droite.

Exemple autonome · C#, construire un arbre de colonnesvar t = new DataTree<Point3d>(); for (int i = 0; i < 5; i++) for (int j = 0; j < 4; j++) t.Add(new Point3d(i * 20, j * 20, 0), new GH_Path(0, i)); // une branche par colonne

Voir la structure

Param Viewer affiche les chemins et le nombre d'éléments de chaque branche ; un Panel montre les valeurs sous leur chemin. On les place avant de deviner.

Des chemins qui s'allongent

Après quelques opérations, les chemins deviennent longs. Simplify retire les indices communs à toutes les branches, sans changer le rangement.

Piège courant Aplatir pour « faire marcher » une définition. Flatten fait disparaître l'information de rangement, et plus loin un composant qui avait besoin de savoir à quelle courbe appartient un point ne peut plus le savoir.

Schéma 2 · Associer

Deux arbres dans un composant

Quand un composant reçoit deux arbres, il associe d'abord les branches, puis les éléments à l'intérieur de chaque paire de branches. Les branches s'associent dans l'ordre, pas par le nom de leur chemin.

Repère · la règle d'associationbranches : 1re avec 1re, 2e avec 2e… ; la dernière de l'arbre le plus court se répète éléments : même règle dans chaque paire de branches (liste la plus longue) sortie : les chemins de l'entrée principale (clic droit sur l'entrée → Principal)

Préparer l'appariement

Pour associer chaque point à sa courbe, les deux arbres doivent avoir autant de branches, dans le même ordre. Graft, Flatten et Simplify servent souvent à ça.

Un élément pour toute une branche

Une valeur seule (un rayon, une hauteur) s'applique à tous : une branche d'un élément se répète sur toutes les branches et tous les éléments.

Piège courant Croire que {0;1} ira avec {0;1}. Si un arbre a ses branches dans un autre ordre, ou une branche de moins, l'association se décale sans aucun message.

Schéma 3 · Restructurer

Donner la bonne forme

Les composants de l'onglet Sets › Tree déplacent les éléments d'une branche à l'autre sans changer leurs valeurs. On les place juste avant le composant qui exploite la structure.

Repère · Path Mapper{A;B}(i) → {A} réunit les branches d'un même parent {A;B}(i) → {B} regroupe par rang de la sous-liste {A;B}(i) → {i} une branche par rang d'élément (un Flip)

Flip Matrix

Dans une grille rangée par colonnes, Flip Matrix met ensemble les éléments de même rang : les colonnes deviennent des rangées. Il suppose des branches de même longueur.

Trim Tree et Partition List

Trim Tree retire des niveaux à droite pour regrouper par parent. Partition List coupe une liste en paquets de taille fixe, chacun dans sa branche.

Piège courant Écrire un Path Mapper sans regarder les chemins réels. La règle doit avoir autant d'indices que le chemin entrant, sinon le résultat ne suit pas l'intention.

Mise en pratique

Des colonnes et des rangées

Tu construis une grille de 5 × 4 points, tu dessines ses colonnes, puis ses rangées en changeant seulement la forme de l'arbre.

Exercice guidé

  1. Deux Series : S 0, N 20, C 5 pour X ; S 0, N 20, C 4 pour Y.
  2. Clic droit sur l'entrée X d'un Construct Point → Graft, puis relie les deux séries à X et Y.
  3. Branche un Param Viewer sur les points, puis une Polyline.
  4. Ajoute Flip Matrix entre les points et une deuxième Polyline.
  5. Sur une troisième copie, Flatten sur l'entrée de la Polyline.
  6. Compare les trois résultats dans la vue.
Résultat attendu Le Param Viewer montre 5 branches de 4 points. La première Polyline trace 5 colonnes ; après Flip Matrix, la seconde trace 4 rangées : ensemble, une grille. La version aplatie trace une seule polyligne en zigzag par les 20 points.
Défi Obtiens les 16 segments horizontaux séparés, rangés par rangée, pour pouvoir les traiter un à un.

Repères

Aide-mémoire et glossaire

En résumé

Un chemin raconte d'où vient une branche ; un indice s'ajoute chaque fois qu'un composant rend une liste par élément. Deux arbres s'associent branche à branche, dans l'ordre, la dernière répétée. Flatten, Graft, Simplify, Flip Matrix, Trim Tree et Path Mapper donnent à l'arbre la forme voulue, juste avant le composant qui l'exploite. En C#, on recopie les chemins d'entrée pour garder la sortie alignée.

Le défi, une solution

Explode sur les 4 polylignes horizontales : chaque polyligne rend ses 4 segments dans sa branche, soit 4 branches de 4 segments. List Item ou Tree Item isole ensuite un segment par son rang.

Glossaire

Chemin
La suite d'indices {0;2;3} qui nomme une branche.
Branche
Une liste d'éléments rangée sous un chemin.
Entrée principale
L'entrée dont les chemins sont repris en sortie.
Flip Matrix
L'échange des rangées et des colonnes d'un arbre.
Path Mapper
Un composant qui réécrit les chemins selon une règle.
