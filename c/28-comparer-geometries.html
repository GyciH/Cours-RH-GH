Le concept

Comparer deux
géométries

Sur les sept modes de correction de Magpie, un seul juge une forme : GeometryTolerance. Deux apprenants construisent le même cercle, l'un avec Circle, l'autre avec Arc puis Join. Magpie doit les accepter tous les deux, et refuser un cercle décalé d'un millimètre de trop.

55 min de lecture et de QCM Prérequis · 24 sérialisation · 03 collections Exemples · GeometryFingerprint, GeometrySampler, ComparaisonGeometrie (Magpie)

L'idée en une phrase

On ramène chaque géométrie à une empreinte : sa famille, sa fermeture, et un nuage de points posés dessus. Deux nuages se comparent par leur écart maximal, qu'on confronte à une tolérance.

L'analogie

Vérifier un dessin au calque. On ne demande pas dans quel ordre les traits ont été tracés : on pose le calque de la solution par-dessus et on cherche l'endroit où les deux s'éloignent le plus.

À la fin, tu sais

  1. ramener tout type Grasshopper à quatre familles ;
  2. expliquer comment une surface devient un nuage de points ;
  3. calculer une distance de Hausdorff bilatérale ;
  4. dire pourquoi l'ordre des filtres compte.
À retenir On vérifie la forme obtenue, pas le chemin suivi. Un nuage de points n'a pas d'ordre : il ignore le sens d'une courbe, sa couture, le paramétrage UV d'une surface et l'ordre des sommets d'un maillage, qui changent tous d'une construction à l'autre.

Schéma 1 · Quatre familles

Des dizaines de types, quatre cas à traiter

Grasshopper emballe chaque géométrie dans un « goo » (GH_Curve, GH_Box…). ScriptVariable() rend la géométrie Rhino qu'il contient ; un switch sur son type la range dans une famille.

GeometryFingerprint.cs · 62–86, condenséobject raw = goo is IGH_GeometricGoo geometric ? geometric.ScriptVariable() : goo; switch (raw) { case Point3d point: return FromPoint(point); case Circle circle: return FromCurve(new ArcCurve(circle)); case Curve curve: return FromCurve(curve); case Mesh mesh: return FromMesh(mesh); case Box box: return FromBrep(box.ToBrep()); … default: throw new NotSupportedException($"Aucune empreinte géométrique définie pour …"); }

Le filtrage par motif

case Circle circle: teste le type et, s'il convient, nomme la variable dans la foulée. L'ordre des case compte : le premier qui convient gagne. Les types précis (Line, Arc…) passent avant Curve, qui ramasse le reste.

Ce que l'empreinte ignore

Le sens de parcours, la couture, le paramétrage UV, l'ordre des sommets, le nombre de faces (commentaire des lignes 22–26). Un exercice qui porte sur l'un d'eux se corrige par un mode numérique, pas par celui-ci.

Piège courant Une réponse d'un type sans empreinte (un plan, par exemple). Compute lève NotSupportedException ; ComparaisonGeometrie retombe alors sur la comparaison stricte des octets sérialisés (cours 24), sans aucune tolérance, et le dit dans son message.

Schéma 2 · Échantillonner

D'une surface à un nuage régulier

Une courbe reçoit 200 points à longueur d'arc égale (DivideByCount). Une surface est d'abord maillée, puis chaque triangle est quadrillé au pas visé, et une grille ne garde qu'un point par case.

GeometrySampler.cs · 183–213, condenséprivate static double Spacing(Mesh mesh) { double area = AreaMassProperties.Compute(mesh).Area; // repli : diagonale² de la boîte double relative = area > 0 ? Math.Sqrt(area / TargetCloudSize) : 0; // TargetCloudSize = 2500 return Math.Max(AbsoluteSpacing(), relative); } internal static double AbsoluteSpacing() => (tolérance du document, ou 0.001) * AbsoluteSpacingFactor; // AbsoluteSpacingFactor = 100

Deux régimes

Avec la tolérance par défaut (0,001), le pas absolu vaut 0,1. Le pas relatif le dépasse dès que l'aire dépasse 2500 × 0,1², soit 25 unités² : au-delà, le pas grandit avec l'objet pour tenir le budget de 2500 points.

Le crible

Un sommet partagé par six faces tombait six fois dans le nuage. Il tombe six fois dans la même case et n'est retenu qu'une fois. Le point conservé est le point réel, jamais le centre de la case.

Piège courant Laisser la tolérance à 0. Deux constructions ne se rejoignent jamais mieux que le pas : Magpie prend alors 2 × le pas (ToleranceDeRepli). Sur un grand objet, ce pas suit la taille ; un exercice qui porte sur une grande surface doit fixer Tolerance.

Schéma 3 · L'écart maximal

La distance de Hausdorff, dans les deux sens

Pour chaque point d'un nuage, on cherche le point le plus proche de l'autre. On garde la pire de ces distances. Puis on recommence dans l'autre sens, et on garde la plus grande des deux.

GeometrySampler.cs · 259–291, simplifié (l'original sort de la boucle dès une distance nulle)public static double Hausdorff(Point3d[] a, Point3d[] b) => Math.Max(Directed(a, b), Directed(b, a)); private static double Directed(Point3d[] from, Point3d[] to) { double worst = 0; foreach (Point3d p in from) { double nearest = double.MaxValue; foreach (Point3d q in to) nearest = Math.Min(nearest, (p - q).SquareLength); // pas de racine dans la boucle if (nearest > worst) worst = nearest; } return Math.Sqrt(worst); }

Pourquoi les deux sens

Un demi-cercle posé sur le cercle attendu : chacun de ses points est sur la référence, l'écart de lui vers elle est nul. Mais la moitié manquante est loin de lui : c'est le sens inverse qui le révèle.

Le coût

Chaque point est confronté à tous ceux de l'autre nuage : 2500 × 2500 × 2, environ 12 millions d'opérations, moins de 200 ms d'après le journal. Comparer les carrés évite 12 millions de racines : une seule suffit, à la fin.

Piège courant La courbe qui repasse au même endroit. Un aller-retour donne le même nuage que l'aller seul : Hausdorff ne voit rien. D'où un dernier contrôle sur la longueur, avec un seuil à 2 × tolérance : une approximation diffère un peu en longueur, un aller-retour du double.

Glossaire

Empreinte
Ce qu'on retient d'une géométrie pour la comparer : famille, fermeture, longueur, nuage.
Nuage de points
Un ensemble de points sans ordre, posés sur la géométrie.
Pas (spacing)
L'écart visé entre deux points du nuage ; le plancher de mesure.
Hausdorff
La plus grande distance d'un point d'un nuage au plus proche de l'autre, dans les deux sens.
Tolérance
L'écart maximal admis, en unités du modèle.
